# Каталог матеріалів справи

> Для кожного матеріалу: тип, зміст (ключові деталі, які мають бути в документі дослівно), умова відкриття,
> що з нього випливає. Позначки: 🎯 — веде до правди; 🐟 — хибний слід (red herring); 🔑 — містить ключ для запиту.

## Механіка відкриття

**Етапи:** 1 (стартова тека) → питання Q1 → 2 (кримінальне провадження: доступні судові запити) → Q2 → 3 (звуження) → Q3 (фінал).

**Типи запитів** (форма в застосунку: тип + об'єкт + за потреби «що пред'являємо»):
| Код | Запит | Об'єкт | Доступно |
|---|---|---|---|
| `INT` | Допит / повторний допит | ПІБ особи + (для повторного) ключ-пред'явлення | з етапу 1 |
| `DB` | Перевірка особи за базами (МВС, судові рішення, звернення) | ПІБ | з етапу 1 |
| `VEH` | Перевірка транспортного засобу | номер (можна частковий) | з етапу 1 |
| `ORG` | Запит до організації | назва організації (+ ПІБ/номер) | з етапу 1 (добровільні), з етапу 2 (за ухвалою) |
| `TEL` | Тимчасовий доступ до даних оператора (ухвала суду) | номер телефону | з етапу 2; номер Вікторії — з етапу 3 |
| `EXP` | Призначення експертизи | вид + об'єкт | з етапу 2 |
| `ADR` | Перевірка адреси / рапорт дільничного | адреса | з етапу 1 |
| `SRCH` | Обшук | особа / місце | лише як результат Q3 |

Неправильний запит → відповідь-відмова від Стасюка (варіанти: «Немає підстав для суду», «Така особа у справі не фігурує»,
«Ця організація даних не має», «Спершу встановіть, що це вбивство», «Експерт просить вихідні дані: …»).

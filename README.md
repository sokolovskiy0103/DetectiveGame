# Справа «Сходи» — кооперативний детектив

Браузерна гра для 2–4 гравців (1,5–2 год). Сервер — цей ПК, гравці підключаються з браузера в локальній мережі.

## Запуск гри
```
uv run python -m app.server            # продовжити збережену гру
uv run python -m app.server --reset    # почати справу з нуля
```
Сервер друкує адресу виду `http://192.168.x.x:8000/` — її відкривають гравці (усі в одній Wi-Fi/мережі).
Windows може запитати дозвіл брандмауера для Python — дозвольте для приватних мереж.
Прогрес зберігається в `data/save.json` після кожної дії. Скинути гру: `--reset` або `POST /api/reset` з самого сервера.

## Як грати
- Ліворуч — матеріали справи (нові позначено «нове»). «⇆ Порівняти» відкриває друге вікно поруч.
- Праворуч — **Запит** (допит, бази, авто, організації, адреси; після Q1 — оператори зв'язку й експертизи),
  **Питання** (контрольні питання етапів + підказки), **Нотатки** (спільні), **Журнал**.
- Запити й відповіді бачать усі гравці. Підказки й помилкові відповіді знімають бали.

## Структура
| Шлях | Що це |
|---|---|
| `story/` | Біблія справи: синопсис, правдива хронологія, персонажі, каталог доказів, етапи, тексти допитів (для автора — спойлери!) |
| `content/case.json` | Документи, правила відкриття (запити), питання, підказки — те, що читає рушій |
| `documents/html/` | Усі ігрові документи (HTML, стиль `_base.css`) |
| `assets/photos/` | Фото (ComfyUI); `assets/photo_jobs.json` — промпти |
| `app/` | Сервер (FastAPI + WebSocket) і фронтенд (`app/static`) |
| `tools/comfy_gen.py` | Пакетна генерація фото через локальний ComfyUI |
| `tools/md2doc.py` | Протоколи допитів `story/documents/interrogations/*.md` → HTML |
| `tests/` | Наскрізне проходження справи рушієм |

## Перевірка
```
uv run python tests/test_walkthrough.py
```

## Android-застосунок (APK)
Телефон-хост запускає сервер, решта підключаються по QR (Wi-Fi або relay). Модулі:
`core` — платформа (хост, QR, relay, оновлення, web-оболонка; перевикористовується),
`casekit` — рушій справ + екрани (`kit/case.js`), `hub` — сам APK зі списком справ (`DetectiveConfig.kt`),
`dev` — запуск на ПК без Android: `./gradlew :dev:run`, тести: `./gradlew :dev:test`.
Нова справа = папка контенту (як `content/`, `documents/`, `assets/photos/`) + рядок у `hub/build.gradle.kts` (`cases`) і `DetectiveConfig.kt`.

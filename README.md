# Детективні справи

Android-застосунок: кооперативні детективи для 1–4 гравців. **Телефон — хост**: на ньому працює сервер і вся логіка,
решта гравців один раз сканують QR і грають у браузері (Wi-Fi/точка доступу або режим «Інтернет» через relay).

**Завантажити:** [останній реліз](https://github.com/sokolovskiy0103/DetectiveGame/releases/latest) → `DetectiveCases.apk`.
Застосунок сам перевіряє оновлення на GitHub.

Зараз у застосунку: **«Сходи»** (`cases/stairs`) і **«Родина»** (`cases/rodyna`).

## Як влаштовано

| Модуль / тека | Що це |
|---|---|
| `core/` | Платформа, спільна для будь-яких ігор на телефоні-хості: сервер, кімната, QR, relay, самооновлення, web-оболонка (`shell.js`, `ui.css`), звуки. Походить із [party_games](https://github.com/sokolovskiy0103/party_games). |
| `casekit/` | Рушій справ (пошук збігів запитів, суддя відповідей, бали) + екрани справи (`web/kit/case.js`). Однаковий для всіх справ. |
| `hub/` | Сам APK. Збирає всі `cases/*` у застосунок; список справ у лобі генерується автоматично. |
| `cases/<id>/` | **Контент однієї справи** — тут пишуться нові справи. Див. [docs/NEW_CASE.md](docs/NEW_CASE.md). |
| `tools/` | Python-скрипти для авторів: генерація фото (ComfyUI), Markdown→HTML бланки. |
| `dev/` | Запуск на ПК без телефона та тести рушія. |

## Команди

- Зіграти на ПК: `./gradlew :dev:run` — виведе адреси хоста й гравця; `--args="3"` відкриє сітку з 3 вікнами.
- Тести рушія (повне проходження «Сходів» і «Родини»): `./gradlew :dev:test`.
- Перевірка JS: `find core/src/main/assets/web casekit/src/main/assets/web -name "*.js" -print0 | xargs -0 -n1 node --check`.
- APK збирає CI (Android SDK локально не потрібен): кожен push у `main` → тести → підписаний APK → реліз `v1.0.<run>`.
  Повідомлення коміту стає описом релізу; частина вище `---` показується у вікні оновлення.

## Нова справа

Коротко: створити `cases/<id>/`, покласти `case.json`, `documents/`, `photos/`, `avatars/`, `rules.html` — і запушити.
Для нових форматів і механік код можна й варто розширювати. Повна інструкція, формат `case.json` і генерація зображень — у [docs/NEW_CASE.md](docs/NEW_CASE.md).

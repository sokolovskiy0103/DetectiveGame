Мета

Разом розкрийте справу: вивчайте матеріали, надсилайте запити слідчому й відповідайте на контрольні питання етапів.

Як грати

  1. Матеріали — документи справи; нові позначені «нове».
  2. Запит — допит, бази, авто, організації, адреси. Номери, адреси й прізвища беріть із документів.
  3. Питання — контрольні питання етапів. Підказки й помилки знімають бали.
  4. Нотатки — спільні для всієї групи. Запити й відповіді бачать усі.
